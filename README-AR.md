# موقع Zooto 💙

## التشغيل
- افتح `index.html` في المتصفح للتجربة محليًا.
- ارفع **محتويات المجلد** إلى مستودع GitHub، وليس ملف ZIP نفسه.
- الصور موجودة داخل `images/`، فلا تفصلها عن المشروع.

## ملاحظة مهمة قبل النشر
هذا إصدار ثابت Static مناسب للتجربة وCloudflare Pages. إجابات الاختبار وكلمة السر والرسالة النهائية موجودة في `config.js`، وبالتالي يمكن لأي شخص تقني فتح ملفات الموقع ورؤيتها؛ هذا ليس تحققًا آمنًا من جهة الخادم. لا تضع معلومات سرية حقيقية هنا.

**ملاحظة عن الرسالة النهائية:** النص المتاح في ملفات المشروع كان جزءًا افتتاحيًا وجزءًا ختاميًا فقط، لذلك تم وضعهما كما هما مع علامة `...` بينهما. لم أستبدل العلامة بنص مخترع. استبدل `finalMessage` في `config.js` بالنص الكامل الأصلي عندما يكون متاحًا لديك.
